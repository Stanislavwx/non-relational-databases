# Лабораторна робота №6

**Тема:** Робота з нереляційною моделлю бази даних NoSQL типу «ключ-значення» Redis  
**Мета:** Набуття практичних навичок роботи з NoSQL СКБД Redis, вивчення базових і спеціалізованих структур даних (Strings, Lists, Sets, Hashes, Sorted Sets), робота з лічильниками, часом життя ключів (TTL), транзакціями, патернами пошуку, моніторингом та тестуванням швидкодії.

## Предметна область

Для виконання лабораторної роботи обрано **Варіант 6 — «Бібліотечна система»**, що логічно продовжує предметну область попередніх робіт (`library_db`):
- **Рядки (Strings):** загальна інформація про бібліотеку (назва, адреса, графік роботи, контакти);
- **Лічильники:** щоденна кількість відвідувачів, загальний облік книжкового фонду, кількість виданих примірників та активних формулярів;
- **Час життя (TTL):** кешування результатів популярних пошукових запитів, тимчасові токени читачів, обмеження частоти звернень (rate limiting);
- **Списки (Lists):** організація черги попереднього бронювання на рідкісні видання (механізми черги FIFO `RPUSH`/`LPOP` та стека LIFO `LPUSH`/`LPOP`);
- **Множини (Sets):** каталогізація літературних жанрів головного фонду та філій, операції реляційної алгебри (`SINTER`, `SUNION`, `SDIFF`), генератор випадкових рекомендацій (`SRANDMEMBER`);
- **Хеш-таблиці (Hashes):** структуровані картки книг (`library:book:101`) та читацькі формуляри з полями різних типів;
- **Впорядковані множини (Sorted Sets):** лідерборд популярності літературних творів (`library:popular_books`) з автоматичним ранжуванням за кількістю видач (`score`);
- **JSON:** комплексний опис примірника книги з історією відгуків та оцінок читачів;
- **Транзакції та пакетні операції:** атомарне виконання серії команд (`MULTI`/`EXEC`), захищене встановлення без перезапису (`SETNX`), пакетні операції (`MSET`/`MGET`).

## Реалізовані операції та структури даних

### 1. Рядкові дані (Strings) та CRUD-операції
- Запис та читання параметрів бібліотеки:
  ```redis
  SET library:name "Центральна наукова бібліотека ім. Івана Франка"
  GET library:name
  ```
- Оновлення значення та перевірка існування й типу:
  ```redis
  SET library:working_hours "Пн-Пт: 08:30 - 19:00, Сб: 10:00 - 17:00"
  EXISTS library:name
  TYPE library:name
  ```

### 2. Числові лічильники
- Атомарне інкрементування відвідувачів та групове збільшення:
  ```redis
  INCR library:stat:daily_visitors
  INCRBY library:stat:daily_visitors 25
  ```
- Декрементування та операції з плаваючою комою:
  ```redis
  DECRBY library:stat:daily_visitors 4
  INCRBYFLOAT library:finance:penalty_rate 0.75
  ```
- Одночасне зчитування декількох лічильників:
  ```redis
  MGET library:stat:daily_visitors library:stat:books_total library:stat:books_issued
  ```

### 3. Час життя ключів (TTL)
- Тимчасовий кеш запиту (TTL = 300 с) та подовження через `EXPIRE`:
  ```redis
  SETEX library:cache:search:kobzar 300 "Тарас Шевченко - Кобзар, 1840"
  EXPIRE library:cache:search:kobzar 600
  ```
- Зняття обмеження за часом (персистентність):
  ```redis
  PERSIST library:cache:search:kobzar
  ```

### 4. Списки (Lists)
- Формування черги на книгу та додавання пільговика на початок:
  ```redis
  RPUSH library:queue:book:101 "Читач #1001" "Читач #1002"
  LPUSH library:queue:book:101 "Читач #1000 (Пільговий)"
  ```
- Обслуговування клієнта у режимі FIFO:
  ```redis
  LPOP library:queue:book:101
  ```

### 5. Множини (Sets)
- Додавання та аналіз множин жанрів:
  ```redis
  SADD library:genres "поезія" "роман" "драма" "новела"
  SADD library:branch1:genres "роман" "детектив" "фантастика"
  ```
- Перетин (`SINTER`), об'єднання (`SUNION`) та різниця (`SDIFF`):
  ```redis
  SINTER library:genres library:branch1:genres
  SDIFF library:genres library:branch1:genres
  ```

### 6. Хеш-таблиці (Hashes)
- Створення картки книги з кількома атрибутами:
  ```redis
  HSET library:book:101 title "Кобзар" author "Тарас Шевченко" year 1840 pages 115 price 350.50
  HGETALL library:book:101
  ```
- Атомарний інкремент сторінок:
  ```redis
  HINCRBY library:book:101 pages 10
  ```

### 7. Впорядковані множини (Sorted Sets)
- Ведення лідерборду популярності книг за кількістю читань:
  ```redis
  ZADD library:popular_books 98 "Кобзар" 85 "Лісова пісня" 76 "Тіні забутих предків" 91 "Місто"
  ```
- Отримання топ-3 видань та збільшення рейтингу:
  ```redis
  ZREVRANGE library:popular_books 0 2 WITHSCORES
  ZINCRBY library:popular_books 7 "Лісова пісня"
  ```

### 8. Транзакції, пакетні операції та сканування
- Атомарний транзакційний блок:
  ```redis
  MULTI
  SET library:announcement "Бібліотека переходить на літній графік"
  INCR library:stat:daily_visitors
  EXEC
  ```
- Безпечне ітеративне сканування замість блокуючого `KEYS *`:
  ```redis
  SCAN 0 MATCH library:* COUNT 10
  ```

## Інструкція із запуску

1. **Запустити Redis-сервер** (якщо встановлено локально або через Docker):
   - Локально:
     ```bash
     redis-server
     ```
   - Або через Docker:
     ```bash
     docker run -d --name redis-lab -p 6379:6379 redis:alpine
     ```

2. **Підключитися через консольний клієнт:**
   ```bash
   redis-cli
   ```

3. **Виконати команди зі скрипта:**
   - Швидкий запуск без виводу коментарів та з відображенням кирилиці:
     ```bash
     grep -v '^[[:space:]]*#' lab6_script.redis | redis-cli --raw
     ```
   - Або покроково в інтерактивному режимі:
     ```bash
     redis-cli --raw
     ```
