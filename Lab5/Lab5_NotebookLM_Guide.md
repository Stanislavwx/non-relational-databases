## 1. Вступ до нереляційних баз даних та концепції масивів

### 1.1. Що таке NoSQL і чому виникла потреба в масивах?
У класичних реляційних базах даних (таких як PostgreSQL чи MySQL) дані зберігаються у вигляді двовимірних таблиць із фіксованими стовпцями. Для збереження списку значень (наприклад, кількох жанрів однієї книги або кількох телефонних номерів клієнта) реляційна модель вимагає **першої нормальної форми (1NF)**:
1. Забороняється зберігати масив або список в одній комірці.
2. Необхідно створити окрему таблицю (наприклад, `book_genres`), де зберігається зовнішній ключ `book_id` та назва жанру.
3. Щоб прочитати книгу разом з усіма її жанрами, СКБД змушена виконувати операцію **`JOIN`**, яка на великих обсягах даних створює суттєве навантаження на процесор і дискову підсистему.

**Документоорієнтована СКБД MongoDB** кардинально змінює цей підхід:
- Одиницею збереження даних є **документ** (у форматі BSON — Binary JSON).
- Документ може містити складні ієрархічні структури: вкладені об'єкти (embedded documents) та **масиви (arrays)**.
- **Масив у MongoDB** — це впорядкований список елементів будь-якого типу (рядки, числа, дати, інші масиви або навіть цілі вкладені документи).
- Завдяки масивам зв'язок «один-до-багатьох» (1:N) у межах розумного розміру зберігається прямо всередині одного документа. Читання такого документа виконується за **одне дискове звернення** без жодних операцій `JOIN`.

```
Реляційний підхід (2 таблиці + JOIN):
 Таблиця books: [ id: 1, title: "Кобзар" ]
 Таблиця genres: [ book_id: 1, genre: "поезія" ], [ book_id: 1, genre: "класика" ]

Підхід MongoDB (1 цілісний документ):
 {
   "_id": ObjectId("..."),
   "title": "Кобзар",
   "genres": ["поезія", "класика"]
 }
```

### 1.2. Анатомія масиву в BSON-документі
- **Ім'я поля масиву (Array Field):** ключ документа, значенням якого є список (наприклад, `genres` або `ratings`).
- **Індексація (Zero-based Indexing):** як і в більшості мов програмування, індексація елементів у масиві починається з нуля (`0`, `1`, `2`, ...).
- **Позиційний доступ (Dot Notation):** щоб звернутися до конкретного елемента за індексом, використовується запис у лапках через крапку: `"genres.0"`.
- **Multikey Indexes (Мультиключові індекси):** якщо створити індекс для поля-масиву (`db.books.createIndex({ genres: 1 })`), MongoDB створює індексний запис для *кожного окремого елемента* масиву. Це забезпечує блискавичний пошук документів за будь-яким значенням всередині масиву.

## 2. Предметна область лабораторної роботи (`library_db`)

У лабораторії досліджується база даних електронного каталогу бібліотеки — **`library_db`**.

### Колекція `books` (Книги):
Кожен документ представляє літературний твір і містить:
- `title` (String) — назва книги («Кобзар», «Місто», «Земля» тощо);
- `year` (Int32) — рік першого видання;
- `genres` (Array of Strings) — **масив рядків**, де перелічено жанри твору (наприклад, `["поезія", "класика"]`);
- `pages` (Int32) — кількість сторінок;
- `price` (Int32) — ціна в гривнях;
- `in_stock` (Boolean) — наявність у фонді бібліотеки чи на складі;
- `ratings` (Array of Int32) — **масив числових оцінок** від читачів (наприклад, `[5, 4, 5, 4]`), доданий для демонстрації арифметичних операцій над елементами масиву;
- `author` (Embedded Document) — вкладений документ із даними про автора (`name`, `country`, `birth_year`).

## 3. Детальний аналіз усіх операторів лабораторної роботи №5

### Блок 1. Запити вибірки з масиву (Querying Arrays)

#### 1.1. Пошук за значенням одного елемента (Implicit Array Search)
У MongoDB, якщо поле є масивом, запит на рівність скаляру `{ genres: "класика" }` автоматично шукає документи, де масив містить хоча б один такий елемент. Розгортати масив не потрібно!
```javascript
// Знайти всі книги, де серед жанрів присутня "класика"
db.books.find(
  { genres: "класика" },
  { title: 1, genres: 1, _id: 0 }
)
```
- **Результат:** книги «Кобзар» (`["поезія", "класика"]`), «Захар Беркут» (`["історична повість", "класика"]`), «Тигролови» (`["пригодницький роман", "класика"]`).

#### 1.2. Пошук за кількома параметрами з оператором `$all`
Оператор `$all` вимагає, щоб масив містив **усі** зазначені елементи одночасно. При цьому порядок розташування елементів у масиві та наявність інших значень значення не мають.
```javascript
// Знайти книги, які одночасно мають жанри "поезія" І "класика"
db.books.find(
  { genres: { $all: ["поезія", "класика"] } },
  { title: 1, genres: 1, _id: 0 }
)
```
- **Результат:** лише книга «Кобзар». Твори, у яких є лише один із цих жанрів, відсікаються.

#### 1.3. Пошук за позиційним індексом елемента (`field.index`)
Якщо критерій вимагає перевірки значення на конкретній позиції, використовується точкова нотація в лапках:
```javascript
// Знайти книги, де першим жанром (індекс 0) є "роман"
db.books.find(
  { "genres.0": "роман" },
  { title: 1, genres: 1, _id: 0 }
)
```
- **Результат:** «Борислав сміється» (`["роман", "соціальна проза"]`) та «Місто» (`["роман", "модернізм", "урбаністика"]`). Якщо б слово «роман» стояло на другій позиції (індекс 1), документ не потрапив би у вибірку.

### Блок 2. Вибірка за довжиною масиву (`$size`)

Оператор `$size` перевіряє точну кількість елементів у масиві:
```javascript
// Книги, що мають рівно два жанри:
db.books.find({ genres: { $size: 2 } }, { title: 1, genres: 1, _id: 0 })

// Книги, що мають рівно три жанри:
db.books.find({ genres: { $size: 3 } }, { title: 1, genres: 1, _id: 0 })

// Книги, що мають рівно один жанр:
db.books.find({ genres: { $size: 1 } }, { title: 1, genres: 1, _id: 0 })
```
> [!IMPORTANT]
> **Питання викладача:** Чи можна написати `{ genres: { $size: { $gt: 2 } } }` для пошуку масивів довжиною більше 2?
> **Відповідь студента:** Ні! Вбудований оператор `$size` у MongoDB приймає **тільки точне скалярне число**. Він не підтримує діапазонні оператори порівняння (`$gt`, `$lt`). Щоб здійснити вибірку за діапазоном довжини, використовують вираз агрегації `$expr: { $gt: [{ $size: "$genres" }, 2] }` або зберігають окреме поле довжини `genres_count`.

### Блок 3. Управління вибіркою масиву в проекції (`$slice`)

Оператор проекції `$slice` регулює підмножину елементів масиву, яку сервер передає клієнту. Важливо: документ у базі даних не змінюється — змінюється лише вид повернених даних!

#### Варіант 1: Одне число (перші або останні N елементів)
- **Додатне число $N$:** повертає перші $N$ елементів.
  ```javascript
  // Повернути перший жанр книги "Місто":
  db.books.find({ title: "Місто" }, { title: 1, genres: { $slice: 1 }, _id: 0 })
  // Результат: genres: ["роман"]
  ```
- **Від'ємне число $-N$:** повертає останні $N$ елементів з кінця масиву.
  ```javascript
  // Повернути останній жанр книги "Місто":
  db.books.find({ title: "Місто" }, { title: 1, genres: { $slice: -1 }, _id: 0 })
  // Результат: genres: ["урбаністика"]
  ```

#### Варіант 2: Масив двох чисел `[skip, limit]` (пагінація по масиву)
- Перше число — кількість елементів, які треба пропустити (`skip`).
- Друге число — кількість елементів, які треба повернути (`limit`).
```javascript
// Пропустити 1 елемент і повернути 2 наступні:
db.books.find({ title: "Місто" }, { title: 1, genres: { $slice: [1, 2] }, _id: 0 })
// Результат: genres: ["модернізм", "урбаністика"]

// Відлік з кінця: починаючи з передостаннього повернути 1 елемент:
db.books.find({ title: "Місто" }, { title: 1, genres: { $slice: [-2, 1] }, _id: 0 })
// Результат: genres: ["модернізм"]
```

### Блок 4. Додавання нових даних до масиву (`$push`, `$addToSet`, `$each`)

| Оператор | Поведінка щодо дублікатів | Створення поля | Призначення |
| :--- | :--- | :--- | :--- |
| **`$push`** | Дозволяє дублікати (додає завжди) | Створює масив, якщо його не було | Додавання в кінець масиву |
| **`$addToSet`** | Забороняє дублікати (масив як Set) | Створює масив, якщо його не було | Додавання унікальних значень |
| **`$each`** | Залежить від базового оператора | Застосовується з `$push`/`$addToSet` | Масове додавання кількох елементів |

#### 4.1. Додавання без контролю унікальності (`$push`)
```javascript
db.books.updateOne(
  { title: "Кобзар" },
  { $push: { genres: "драма" } }
)
// modifiedCount: 1. До масиву ["поезія", "класика"] додано "драма"
```

#### 4.2. Додавання лише унікальних елементів (`$addToSet`)
```javascript
// Спроба додати "драма", яка вже є в масиві:
db.books.updateOne(
  { title: "Кобзар" },
  { $addToSet: { genres: "драма" } }
)
// modifiedCount: 0! Змін не відбулося, дублікат відхилено.

// Додавання нового значення:
db.books.updateOne(
  { title: "Кобзар" },
  { $addToSet: { genres: "ілюстроване видання" } }
)
// modifiedCount: 1. Елемент успішно додано.
```

#### 4.3. Одночасне додавання групи елементів (`$push` + `$each`)
Без модифікатора `$each` оператор `$push: { genres: ["епос", "героїка"] }` вставив би цілий вкладений масив всередину масиву (`[["епос", "героїка"]]`). Модифікатор `$each` розпаковує елементи:
```javascript
db.books.updateOne(
  { title: "Захар Беркут" },
  { $push: { genres: { $each: ["епос", "героїка"] } } }
)
// modifiedCount: 1. Обидва жанри додано як окремі елементи.
```

### Блок 5. Вилучення елементів з масиву (`$pop`, `$pull`, `$pullAll`)

#### 5.1. Стекове вилучення крайніх елементів (`$pop`)
Оператор працює подібно до методів стека/черги:
- `1` — вилучає **останній** елемент масиву:
  ```javascript
  db.books.updateOne({ title: "Кобзар" }, { $pop: { genres: 1 } })
  ```
- `-1` — вилучає **перший** елемент масиву:
  ```javascript
  db.books.updateOne({ title: "Захар Беркут" }, { $pop: { genres: -1 } })
  ```

#### 5.2. Вилучення за конкретним значенням або критерієм (`$pull`)
Оператор `$pull` видаляє з масиву **всі входження** елементів, які задовольняють вказане значення чи умову (наприклад, `$gt`):
```javascript
// Видалити жанр "епос" з масиву:
db.books.updateOne({ title: "Захар Беркут" }, { $pull: { genres: "епос" } })
```

#### 5.3. Пакетне вилучення списку значень (`$pullAll`)
Якщо потрібно видалити кілька конкретних значень одночасно, `$pullAll` приймає масив значень:
```javascript
db.books.updateOne(
  { title: "Місто" },
  { $pullAll: { genres: ["роман", "модернізм"] } }
)
// Видаляє і "роман", і "модернізм". Залишається лише "урбаністика".
```

### Блок 6. Зміна значень масиву за індексом (`$set`, `$inc`)

Для оновлення елемента на конкретній позиції використовується точкова нотація з числовим індексом:

#### 6.1. Заміна рядкового значення за індексом (`$set`)
```javascript
// Замінити нульовий елемент масиву в книзі "Земля":
db.books.updateOne(
  { title: "Земля" },
  { $set: { "genres.0": "соціальна повість" } }
)
```

#### 6.2. Атомарне інкрементування числового елемента (`$inc`)
Оператор `$inc` додає вказане число до існуючого числового значення (або віднімає при від'ємному значенні):
```javascript
// Початковий стан ratings: [5, 4, 5, 4]
// Збільшити першу оцінку на 1:
db.books.updateOne(
  { title: "Кобзар" },
  { $inc: { "ratings.0": 1 } }
)
// Кінцевий стан ratings: [6, 4, 5, 4]
```

### Блок 7. Робота з регулярними виразами (`$regex`)

Регулярні вирази в MongoDB базуються на стандарті **PCRE (Perl Compatible Regular Expressions)** і застосовуються для пошуку рядків за масками без необхідності повнотекстового індексу.

#### Основні синтаксичні форми:
1. JSON-об'єкт: `{ <field>: { $regex: "шаблон", $options: "прапорці" } }`
2. JS-літерал: `{ <field>: /шаблон/прапорці }`

#### Ключові метасимволи:
- **`^` (циркумфлекс):** фіксація на початку рядка. Наприклад, `^Т` — знаходить рядки, що починаються з літери «Т».
- **`$` (долар):** фіксація на кінці рядка. Наприклад, `я$` — знаходить рядки, що закінчуються на літеру «я».
- **`.` (крапка):** будь-який один символ.
- **`*` / `+` / `?`:** квантифікатори (0 і більше, 1 і більше, 0 або 1).
- **`[ ]` (символьний клас):** будь-який символ із набору.

#### Опції регулярних виразів:
- **`i` (case-insensitivity):** не розрізняти великі та малі літери.
- **`m` (multiline):** багаторядковий режим (символи `^` і `$` спрацьовують для кожного рядка у тексті з переносами `\n`).
- **`x` (extended):** ігнорування пробілів і коментарів усередині складного шаблону.
- **`s` (dotAll):** дозволяє крапці `.` відповідати також символу нового рядка `\n`.

#### Приклади з лабораторної роботи:
```javascript
// 1) Книги, назва яких починається з 'Т' (^):
db.books.find({ title: { $regex: "^Т" } }, { title: 1, year: 1, _id: 0 })
// Знайдено: "Тіні забутих предків", "Тигролови"

// 2) Книги, назва яких закінчується на 'я' ($):
db.books.find({ title: { $regex: "я$" } }, { title: 1, year: 1, _id: 0 })
// Знайдено: "Борислав сміється", "Лісова пісня", "Земля"

// 3) Пошук без врахування регістру (i):
db.books.find({ title: { $regex: "^кобзар$", $options: "i" } }, { title: 1, year: 1, _id: 0 })
// Знайдено: "Кобзар" (1840 рік)
```

## 4. Повний симулятор усного захисту (Питання та ідеальні відповіді)

### Офіційні питання з методички (Розділ 1.5):

#### Питання 1: Як можна виконати вибірку з масиву?
**Ідеальна відповідь:**
«У MongoDB вибірку з масиву можна здійснити кількома основними способами:
1. За прямим скалярним значенням (`{ genres: "роман" }`) — СКБД автоматично сканує масив і повертає документ, якщо елемент присутній у масиві.
2. За точним збігом усього масиву (`{ genres: ["поезія", "класика"] }`) — вимагає точного збігу всіх елементів і їхньої черговості.
3. За позиційним індексом через точкову нотацію (`{ "genres.0": "роман" }`) — перевіряє значення на конкретній позиції.
4. За оператором `$all` (`{ genres: { $all: ["поезія", "класика"] } }`) — відбирає документи, де містяться всі зазначені елементи в будь-якому порядку.
5. За складеними умовами через `$elemMatch` — перевіряє виконання кількох умов для одного й того ж елемента.
6. За допомогою проекції `$slice` — повертає підмножину елементів масиву клієнту.»

#### Питання 2: Перерахуйте основні оператори пошуку в масиві та охарактеризуйте їх функції.
**Ідеальна відповідь:**
«Основними операторами пошуку в масиві є:
- `$all` — перевіряє входження всіх елементів із зазначеного списку в масив.
- `$size` — перевіряє точну довжину масиву на рівність скалярному числу.
- `$elemMatch` — відбирає документи, в яких хоча б один елемент масиву задовольняє комплексну умову (кілька операторів порівняння).
- `$slice` — оператор проекції, що обмежує кількість повернених значень масиву за позицією чи діапазоном.»

#### Питання 3: Який оператор виконує додавання нових елементів у кінець масиву без перевірки на їх унікальність?
**Ідеальна відповідь:**
«Оператор `$push`. Він безумовно додає елемент у кінець масиву і допускає дублювання однакових значень. Якщо масив раніше був відсутній у документі, `$push` автоматично створює його.»

#### Питання 4: Який оператор виконує додавання нових унікальних елементів у масив?
**Ідеальна відповідь:**
«Оператор `$addToSet`. Він сприймає масив як множину унікальних елементів (Set). Якщо додаване значення вже існує в масиві, документ не модифікується (`modifiedCount: 0`). Якщо значення нове — воно додається.»

#### Питання 5: Охарактеризуйте поняття регулярного виразу та його використання в MongoDB.
**Ідеальна відповідь:**
«Регулярний вираз — це формалізований рядковий шаблон із використанням метасимволів для гнучкого пошуку, зіставлення та фільтрації тексту. У MongoDB підтримується синтаксис Perl Compatible Regular Expressions (PCRE). Застосовується через оператор `$regex` або літерал `/pattern/` для пошуку підрядків, префіксів, суфіксів і нечутливих до регістру фрагментів тексту без побудови текстових індексів.»

#### Питання 6: Охарактеризуйте основні метасимволи та їх використання в регулярних виразах.
**Ідеальна відповідь:**
«Основні метасимволи:
- `^` — прив'язка до початку рядка (`^Т` — назви на літеру Т);
- `$` — прив'язка до кінця рядка (`я$` — закінчення на літеру я);
- `.` — будь-який один символ крім символу нового рядка;
- `*` — повторення попереднього символу від 0 до багатьох разів;
- `+` — повторення від 1 до багатьох разів;
- `?` — входження 0 або 1 раз (необов'язковий символ);
- `[ ]` — клас символів (один символ із перелічених);
- `( )` — групування символів у підшаблони;
- `|` — логічне «АБО» між варіантами;
- `\` — символ екранування спеціальних дій метасимволів.»

#### Питання 7: Яка різниця між операторами `$push` та `$addToSet`?
**Ідеальна відповідь:**
«Різниця полягає у валідації унікальності:
- `$push` завжди додає елемент у кінець масиву і дозволяє появу дублікатів.
- `$addToSet` перед записом перевіряє наявність значення. Якщо значення вже є, операція пропускається і `modifiedCount` дорівнює `0`. Тобто `$addToSet` гарантує унікальність елементів масиву.»

#### Питання 8: Як використовувати оператор `$slice` для управління вибіркою елементів масиву?
**Ідеальна відповідь:**
«Оператор `$slice` використовується в об'єкті проекції запиту:
1. З одним цілим числом $N$: додатне значення повертає перші $N$ елементів (`$slice: 1`), а від'ємне — останні $|N|$ елементів (`$slice: -1`).
2. З масивом із двох чисел `[skip, limit]`: перший параметр задає зміщення від початку або кінця, а другий — кількість елементів для повернення (`$slice: [1, 2]`).»

#### Питання 9: Які опції можна використовувати з оператором `$regex`?
**Ідеальна відповідь:**
«З оператором `$regex` через параметр `$options` можна передавати такі прапорці:
- `i` — ігнорування регістру символів (case-insensitive);
- `m` — багаторядковий режим, де `^` і `$` спрацьовують на початку і кінці кожного рядка у багаторядковому тексті;
- `x` — ігнорування неекранованих пробільних символів всередині шаблону;
- `s` — режим dotAll, що дозволяє крапці `.` відповідати також символу нового рядка `\n`.»

#### Питання 10: Як вилучити конкретний елемент з масиву за його значенням?
**Ідеальна відповідь:**
«За допомогою оператора `$pull`:
`db.books.updateOne({ title: "Захар Беркут" }, { $pull: { genres: "епос" } })`.
Оператор видаляє всі екземпляри зазначеного значення. Якщо потрібно видалити відразу кілька різних значень за списком, використовують оператор `$pullAll`:
`{ $pullAll: { genres: ["роман", "модернізм"] } }`.»

### Додаткові підступні питання від викладача:

#### Підступне питання 1: Чому запит `db.books.find({ genres: ["поезія", "класика"] })` повертає не всі поетичні книги-класики?
**Відповідь:**
«Тому що точний пошук за масивом `{ genres: ["поезія", "класика"] }` вимагає **суворого збігу кількості, значень та порядку слідування**. Якщо у книзі масив записаний як `["класика", "поезія"]` або містить третій жанр `["поезія", "класика", "драма"]`, цей запит її не знайде. Для пошуку за входженням обох елементів незалежно від порядку слід використовувати оператор `$all`.»

#### Підступне питання 2: Що відбудеться, якщо застосувати `$push` без модифікатора `$each` і передати масив `["епос", "героїка"]`?
**Відповідь:**
«MongoDB вставить цей масив як **один вкладений елемент-масив**. Тобто структура стане `["класика", ["епос", "героїка"]]`, а не плоским списком. Щоб розпакувати елементи, обов'язково треба писати `{ $push: { genres: { $each: ["епос", "героїка"] } } }`.»

#### Підступне питання 3: Чи модифікує оператор `$slice` документ у базі даних на диску?
**Відповідь:**
«Ні! Оператор `$slice` у запиті `find()` є **оператором проекції**. Він працює виключно на етапі формування відповіді клієнту, зменшуючи обсяг переданих по мережі даних. Документ на диску залишається повним і недоторканим. (Примітка: існує також модифікатор `$slice` у поєднанні з `$push` для збереження тільки останніх N елементів при оновленні, але в запитах вибірки це чиста проекція).»

#### Підступне питання 4: Чому оператор `$inc` безпечніший за ручне прочитання, збільшення і запис через `$set`?
**Відповідь:**
«Оператор `$inc` є **атомарною операцією на стороні сервера**. СКБД гарантує, що при одночасному зверненні багатьох клієнтів інкремент відбудеться без race conditions (станів гонитви). Якщо ж спочатку читати значення в пам'ять клієнта, додавати 1 у JavaScript і потім писати через `$set`, виникає ризик втрати даних (lost update) через паралельні транзакції.»

## 5. Покрокова структура коду лабораторної роботи (`lab5_script.js`)

Скрипт розроблено за модульним принципом, де кожен блок чітко відповідає пункту завдання:

1. **Ініціалізація та очищення:**
   `db = db.getSiblingDB("library_db"); db.books.drop(); db.books.insertMany([...]);`
   Скрипт гарантує ідемпотентність: при кожному запуску база даних ініціалізується свіжими 10 творами української літератури.
2. **Блок вибірки (Завдання 1):**
   Демонструє пошук скаляра (`genres: "класика"`), логічного «І» для масиву (`$all: ["поезія", "класика"]`) та доступ за першою позицією (`"genres.0": "роман"`).
3. **Блок перевірки довжини (Завдання 2):**
   Перевіряє роботу оператора `$size` для розмірів 2, 3 та 1 елемент.
4. **Блок проекції (Завдання 3):**
   Тестує всі режими `$slice` на романі «Місто»: перший елемент (`1`), останній (`-1`), позиційний зріз (`[1, 2]`) та зріз з кінця (`[-2, 1]`).
5. **Блок додавання (Завдання 4):**
   Порівнює поведінку `$push` (додав `'драма'`) та `$addToSet` (проігнорував повторну `'драма'`, але додав `'ілюстроване видання'`), а також показує пакетне додавання через `$each`.
6. **Блок вилучення (Завдання 5):**
   Демонструє стекове видалення крайніх елементів через `$pop: 1` і `$pop: -1`, видалення значення `'епос'` через `$pull` та видалення списку `['роман', 'модернізм']` через `$pullAll`.
7. **Блок зміни значень (Завдання 6):**
   Показує позиційну зміну рядка через `$set: { "genres.0": "соціальна повість" }` та інкремент числової оцінки через `$inc: { "ratings.0": 1 }`.
8. **Блок регулярних виразів (Завдання 7):**
   Демонструє метасимволи `^Т` (початок), `я$` (кінець) та опцію `i` для регістронезалежного пошуку книги `^кобзар$`.

## 6. Шпаргалка-підсумок для екзамену / захисту

| Дія | Оператор MongoDB | Приклад синтаксису |
| :--- | :--- | :--- |
| **Елемент є в масиві** | Неявний пошук | `{ genres: "поезія" }` |
| **Всі елементи є в масиві** | `$all` | `{ genres: { $all: ["поезія", "роман"] } }` |
| **Елемент на певній позиції** | Точкова нотація | `{ "genres.0": "поезія" }` |
| **Точна довжина масиву** | `$size` | `{ genres: { $size: 3 } }` |
| **Зріз масиву в вибірці** | `$slice` | `{ genres: { $slice: [1, 2] } }` |
| **Додати в кінець (з дублікатами)** | `$push` | `{ $push: { genres: "нове" } }` |
| **Додати унікальне (без дублікатів)**| `$addToSet` | `{ $addToSet: { genres: "унікальне" } }` |
| **Додати групу елементів** | `$each` | `{ $push: { genres: { $each: ["а", "б"] } } }` |
| **Видалити останній / перший** | `$pop` | `{ $pop: { genres: 1 } }` або `-1` |
| **Видалити за значенням** | `$pull` | `{ $pull: { genres: "епос" } }` |
| **Видалити кілька значень** | `$pullAll` | `{ $pullAll: { genres: ["а", "б"] } }` |
| **Змінити елемент за індексом** | `$set` | `{ $set: { "genres.0": "нова назва" } }` |
| **Додати число до елемента** | `$inc` | `{ $inc: { "ratings.0": 1 } }` |
| **Початок рядка** | `$regex: "^..."` | `{ title: { $regex: "^Т" } }` |
| **Кінець рядка** | `$regex: "...$"` | `{ title: { $regex: "я$" } }` |
| **Регістронезалежний пошук** | `$options: "i"` | `{ title: { $regex: "^кобзар$", $options: "i" } }` |
