# Лабораторна робота №5

**Тема:** Робота з масивами в MongoDB  
**Мета:** Вивчити принципи організації та обробки масивів у середовищі MongoDB, навчитися створювати запити для вибірки, фільтрації, управління проекцією та внесення змін до масивних структур даних, а також освоїти використання регулярних виразів для пошуку текстових даних за шаблоном.

## Предметна область

Робота виконується на основі бази даних **`library_db`** («Бібліотека»), створеної у попередніх роботах:
- **`books`** — документи літературних творів (назва `title`, рік `year`, масив жанрів `genres`, кількість сторінок `pages`, ціна `price`, наявність `in_stock`, масив оцінок читачів `ratings`, вкладений автор `author`);
- **`authors`** — документи письменників (ім'я `name`, країна `country`, рік народження `birth_year`, масив жанрів `genres`).

## Реалізовані запити

### 1. Вибірка з масиву з різними умовами
- **Пошук за одним параметром:** книги з жанром «класика».
  ```javascript
  db.books.find({ genres: "класика" }, { title: 1, genres: 1, _id: 0 })
  ```
- **Пошук за кількома параметрами ($all):** книги, що містять одночасно жанри «поезія» та «класика».
  ```javascript
  db.books.find({ genres: { $all: ["поезія", "класика"] } }, { title: 1, genres: 1, _id: 0 })
  ```
- **Пошук за конкретним індексом:** книги, де перший жанр (`genres.0`) — «роман».
  ```javascript
  db.books.find({ "genres.0": "роман" }, { title: 1, genres: 1, _id: 0 })
  ```

### 2. Вибірка за довжиною масиву ($size)
- **Точна кількість елементів:** книги з рівно 2, 3 та 1 жанрами.
  ```javascript
  db.books.find({ genres: { $size: 2 } }, { title: 1, genres: 1, _id: 0 })
  db.books.find({ genres: { $size: 3 } }, { title: 1, genres: 1, _id: 0 })
  ```

### 3. Управління вибіркою масиву ($slice)
- **Вибірка першого/останнього елемента:**
  ```javascript
  db.books.find({ title: "Місто" }, { title: 1, genres: { $slice: 1 }, _id: 0 })
  db.books.find({ title: "Місто" }, { title: 1, genres: { $slice: -1 }, _id: 0 })
  ```
- **Діапазон елементів [skip, limit]:** пропустити 1 елемент і повернути наступні 2:
  ```javascript
  db.books.find({ title: "Місто" }, { title: 1, genres: { $slice: [1, 2] }, _id: 0 })
  ```

### 4. Додавання нових даних до масиву ($push, $addToSet, $each)
- **Додавання без перевірки унікальності ($push):**
  ```javascript
  db.books.updateOne({ title: "Кобзар" }, { $push: { genres: "драма" } })
  ```
- **Додавання унікальних значень ($addToSet):**
  ```javascript
  db.books.updateOne({ title: "Кобзар" }, { $addToSet: { genres: "ілюстроване видання" } })
  ```
- **Масове додавання кількох значень ($push + $each):**
  ```javascript
  db.books.updateOne({ title: "Захар Беркут" }, { $push: { genres: { $each: ["епос", "героїка"] } } })
  ```

### 5. Вилучення елементів з масиву ($pop, $pull, $pullAll)
- **Вилучення крайніх елементів ($pop: 1 для останнього, -1 для першого):**
  ```javascript
  db.books.updateOne({ title: "Кобзар" }, { $pop: { genres: 1 } })
  db.books.updateOne({ title: "Захар Беркут" }, { $pop: { genres: -1 } })
  ```
- **Вилучення за конкретним значенням ($pull):**
  ```javascript
  db.books.updateOne({ title: "Захар Беркут" }, { $pull: { genres: "епос" } })
  ```
- **Вилучення кількох значень ($pullAll):**
  ```javascript
  db.books.updateOne({ title: "Місто" }, { $pullAll: { genres: ["роман", "модернізм"] } })
  ```

### 6. Зміна значень масиву ($set, $inc)
- **Зміна елемента за індексом через $set:**
  ```javascript
  db.books.updateOne({ title: "Земля" }, { $set: { "genres.0": "соціальна повість" } })
  ```
- **Інкремент числового елемента масиву за індексом через $inc:**
  ```javascript
  db.books.updateOne({ title: "Кобзар" }, { $inc: { "ratings.0": 1 } })
  ```

### 7. Робота з регулярними виразами ($regex)
- **Початок рядка (^):** назви книг, що починаються з літери «Т».
  ```javascript
  db.books.find({ title: { $regex: "^Т" } }, { title: 1, year: 1, _id: 0 })
  ```
- **Кінець рядка ($):** назви книг, що закінчуються на літеру «я».
  ```javascript
  db.books.find({ title: { $regex: "я$" } }, { title: 1, year: 1, _id: 0 })
  ```
- **Нечутливість до регістру (опція 'i'):** пошук книги «кобзар» у нижньому регістрі.
  ```javascript
  db.books.find({ title: { $regex: "^кобзар$", $options: "i" } }, { title: 1, year: 1, _id: 0 })
  ```

## Інструкція із запуску

1. Підключення до бази даних у терміналі `mongosh`:
   ```bash
   mongosh library_db
   ```
2. Виконання всіх запитів лабораторної роботи файлом:
   ```bash
   mongosh library_db lab5_script.js
   ```
