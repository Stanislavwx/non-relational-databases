# Лабораторна робота №7

**Тема:** Робота з графовою базою даних. Створення вузлів, додавання та видалення властивостей та міток. Створення відношень між вузлами, додавання властивостей до зв’язків. Вдосконалення операторів Cypher, для того, щоб параметризувати значення, які використовуються під час виконання операторів Cypher. Керування індексами.  
**Мета:** Набуття практичних навичок роботи з графовою СКБД Neo4j та декларативною мовою запитів Cypher, вивчення моделі графів з властивостями та мітками (Labeled Property Graph), опанування методів створення, вибірки та модифікації вузлів і зв'язків, оптимізації виконання запитів через параметризацію та адміністрування індексів.

## Предметна область

Робота поєднує:
1. **Базовий навчальний граф методички (Movie Graph):** вузли `Movie` та `Person`, зв'язки `ACTED_IN`, `DIRECTED`, `HELPED`, `REVIEWED`, маніпулювання мітками (`OlderMovie`, `Female`), властивостями (`tagline`, `roles`, `rating`), параметризовані вибірки та індексація за роком народження `born`.
2. **Адаптація до Варіанта 6 — «Бібліотечна система»** (продовження лабораторних робіт 2–6): моделювання літературного фонду у вигляді графа:
   - Вузли: `Book` (книги), `Author` (автори), `Reader` (читачі), `Genre` (жанри);
   - Відношення: `(:Author)-[:WROTE]->(:Book)`, `(:Book)-[:BELONGS_TO]->(:Genre)`, `(:Reader)-[:BORROWED]->(:Book)`, `(:Reader)-[:REVIEWED]->(:Book)`;
   - Графова аналітика: вибірка колаборацій авторів, книг за спільними читачами, оцінка популярності запозичень та параметризовані пошукові запити.

## Швидкий запуск через Docker Compose

### 1. Запуск СКБД
У терміналі в папці `Lab7` виконайте:
```bash
sudo docker compose up -d
# або без sudo, якщо ваш користувач доданий у групу docker
```

### 2. Перевірка статусу контейнера
```bash
sudo docker compose logs -f
```
Коли з'явиться рядок `Started.` або `Server gRPC API available at ...` — сервер готовий до роботи.

### 3. Доступ до веб-інтерфейсу (Neo4j Browser)
Відкрийте браузер за адресою:
👉 **`http://localhost:7474`**

Параметри авторизації:
- **Connect URL:** `bolt://localhost:7687`
- **Username:** `neo4j`
- **Password:** `password123`

### 4. Автоматичний запуск скрипту через cypher-shell
Скрипт `lab7_script.cypher` промонтовано всередину контейнера за шляхом `/scripts/lab7_script.cypher`:
```bash
sudo docker compose exec neo4j cypher-shell -u neo4j -p password123 -f /scripts/lab7_script.cypher
```
Або відкрийте інтерактивну термінальну консоль Cypher:
```bash
sudo docker compose exec neo4j cypher-shell -u neo4j -p password123
```

### 5. Зупинка контейнера
```bash
sudo docker compose down
```

## Зміст реалізованих завдань

### Завдання 1: Вузли, мітки та властивості
- Створення вузлів `Movie` та `Person` (`CREATE`);
- Пошук та фільтрація вузлів за атрибутами (`MATCH ... WHERE ... RETURN`);
- Додавання та видалення динамічних міток (`SET m:OlderMovie`, `SET p:Female`, `REMOVE p:Female`);
- Перегляд метаданих графа (`CALL db.schema.visualization()`);
- Додавання множинних властивостей (`SET`) та видалення властивостей (`SET prop = null`, `REMOVE prop`).

### Завдання 2: Відношення (зв'язки) та їх властивості
- Створення спрямованих зв'язків між вузлами (`[:ACTED_IN]`, `[:DIRECTED]`, `[:HELPED]`);
- Призначення атрибутів зв'язків: масив ролей `roles` за умовою `CASE`, текстове поле `research`;
- Дослідження обходу графа з фіксацією напрямку та без нього (`-[:HELPED]-` vs `->`);
- Оновлення властивостей зв'язків та їх видалення через `REMOVE`.

### Завдання 3: Параметризація запитів у Cypher
- Формування складного аналітичного запиту з агрегацією `collect(a.name)`;
- Застосування сесійних параметрів (`:param year => 2000`, `:param year => 2006`);
- Багатопараметрична фільтрація (`:params {year: 2006, ratingValue: 65}`) для повторного використання плану виконання запиту (Execution Plan Caching) та захисту від ін'єкцій.

### Завдання 4: Керування індексами
- Створення індексу для властивості `born` вузлів `Person` (`CREATE INDEX ON :Person(born)`);
- Перегляд зареєстрованих індексів у системі (`CALL db.indexes()` / `SHOW INDEXES`);
- Видалення індексу (`DROP INDEX ON :Person(born)`).
